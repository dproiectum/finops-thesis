# Documents de préparation

Ce dossier n'est pas assemblé dans le PDF du mémoire. `PFE_guidelines_summary.md` résume les consignes scolaires et `illustrations_plan_2026_09_27.md` pilote les figures à préparer.

`cadrage/` et `first_step/` conservent les premières formulations du projet, dont certaines hypothèses Azure et des étapes depuis dépassées. Elles servent à retracer les décisions, pas à décrire l'implémentation courante. Pour celle-ci, utiliser les chapitres et les preuves du dossier `audit/`.

Le fichier texte extrait du guide officiel facilite la recherche ; le PDF conservé dans `references/official_guidelines/` reste la référence.
